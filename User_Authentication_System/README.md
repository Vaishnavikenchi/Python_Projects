# User Authentication System in Python

## 📌 Project Description
This is a simple Python mini project that implements a **Signup and Login system** using a dictionary.  
The project allows users to create an account and log in with limited attempts for security.

---

## ✨ Features
- User Signup
- User Login
- Password validation
- Limited login attempts (Account lock after 3 failures)
- Menu-driven program
- Beginner-friendly logic

---

## 🛠️ Technologies Used
- Python 3
- VS Code (for execution)

---

## 📂 Project Structure

User-Authentication-System/
│
├── User.py
└── README.md


## ▶ How to Run the Project
1. Install Python 3
2. Open the project folder in VS Code
3. Open terminal
4. Run the command:
   python User.py


## 🔐 Login Attempts Logic
- User is given **3 attempts** to log in
- After 3 wrong attempts, the account is locked
- This improves security and prevents unauthorized access
