# GuessIt🎯

**GuessIt** is a simple yet engaging Python-based number guessing game where players try to guess a randomly generated number. The game provides smart hints and keeps track of your guesses and attempts, making it interactive and fun for both beginners and Python enthusiasts.  

---

## Features 🌟

- Random number generation (1–100) every game
- Interactive **warm/cold hints** to guide the player
- Counts the **number of attempts**
- Stores **guess history** to track progress
- Friendly and engaging console messages with emojis
- Beginner-friendly Python code, easy to understand and modify

---

## How to Play 🎮

1. Clone or download the repository.
2. Open the project in your Python IDE (e.g., VS Code, PyCharm) or run in the terminal.
3. Run the Python file:
   '''bash
   python guessitnum.py
4.Enter a number between 1 and 100 when prompted.
5.Follow the hints to guess the correct number.
6.The game will display:
  Number of attempts
  Your guess history
7.Guess correctly to win! 🎉
